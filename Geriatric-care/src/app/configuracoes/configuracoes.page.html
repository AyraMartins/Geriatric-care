Como realizar o teste

Instruções para realizar o teste selecionado

Teste de Repouso

Para realizar o teste de repouso, o paciente deve permanecer sentado e tranquilo antes do início da coleta.

Mantenha uma posição confortável e evite conversar ou realizar movimentos desnecessários durante o teste.

Permaneça tranquilo enquanto o sistema registra os batimentos cardíacos.

Teste de Caminhada

Para realizar o teste de caminhada, o paciente deve caminhar em um ritmo confortável e constante.

Evite correr ou realizar movimentos muito intensos.

O objetivo é registrar os batimentos cardíacos durante a caminhada.

Caso o paciente apresente algum desconforto, interrompa a atividade.

Teste de Exercício Intenso

Este teste deve ser realizado somente quando houver orientação adequada para esse nível de esforço.

Durante o teste, os batimentos cardíacos serão acompanhados pelo sistema.

Se houver dor, tontura, falta de ar ou qualquer mal-estar, interrompa a atividade e procure ajuda.
